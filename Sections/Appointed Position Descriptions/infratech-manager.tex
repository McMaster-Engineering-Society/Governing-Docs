\subsubsection{Infrastructure Technology Manager(s)}
\label{infrastructure-technology-managers}
The Information Technology Manager(s) shall:

\begin{enumerate}
 \item    
  Oversee and manage the Infrastructure Technology Committee. 
 \item    
  Be responsible for the maintenance infrastructure technology GitHub Repo. 
 \item     
  Ensure all infrastructure technology is either original work or properly referenced. 
 \item     
  Report to the VP Internal. 
 \item    
  Be a position held by a maximum of three people. 
  
\end{enumerate}
